## 一分钟速览

> 没时间？记住这三句就够用。

| # | 结论 | 记住它 |
|---|---|---|
| ① | **中鸣控制器只会"播放"存好的程序**，不会边看边改 | 它不是司机，是发动机控制盒 |
| ② | **想让它临场改主意，只有两条路**：远处喊话，或把脑子塞进去 | 没有第三种 |
| ③ | **九成需求其实不需要 Agent**，写死程序更稳、更便宜 | 先问"要不要改主意" |

## 打个比方：控制盒与司机

```text
   中鸣控制器（E6/E7/M5/M6/E3/C7）
   ┌─────────────────────────┐
   │  只执行提前存进去的程序   │  ← 按一下就跑，不会边看路边改主意
   └─────────────────────────┘

   AI Agent
   ┌─────────────────────────┐
   │  能看 · 能想 · 能改路线    │  ← 真正的"司机"
   └─────────────────────────┘

   矛盾就在这里：
   控制盒不接受"边看边开"，只接受"提前录好的路线"。
```

所以所有方案，本质上都在回答同一个问题：**司机和发动机控制盒之间，怎么打交道？**

## 三种搞法，从便宜到贵

### ① 外挂 —— 用对讲机指挥司机

> 给机器人加个 IoT 模块，Agent 在远处发口令，机器人收到就执行。

| 维度 | 说明 |
|---|---|
| 💰 代价 | 最低，模块现成 |
| 🕐 延迟 | 来回约 **0.5–2 秒** |
| 🎯 能做什么 | "前进""左转""停"这类**开关式口令** |
| 🚫 做不到 | "慢一点、再慢一点"这种**连续调节** |

### ② 换脑 —— 把司机塞进车里

> 把控制器换成能装程序的板子，Agent 直接住进去。

| 维度 | 说明 |
|---|---|
| 💰 代价 | 中等：接线 + 装驱动 + 算供电 |
| 🕐 延迟 | 约 **10–50 毫秒** |
| 🎯 能做什么 | 真闭环：视觉跟着目标走、边动边修正 |
| ⚠️ 坑 | 插头、电压、线序都得重新对一遍 |

### ③ 不动 Agent —— 装个定速巡航

> 跟随、避障这类事，直接写死在控制器里。

| 维度 | 说明 |
|---|---|
| 💰 代价 | 最低，不用买任何东西 |
| 🎯 能做什么 | 一件事，做得很稳 |
| 🚫 局限 | 换场景就得重写 |

<div align="center">

**📌 九成的人其实要的是第 ③ 种，却以为自己在要第 ① 或第 ② 种。**

</div>

## 你手上的型号属于哪一类

| 型号 | 能不能把 Agent 装进去 | 备注 |
|---|:---:|---|
| E6 | ❌ | 只能下载程序 |
| E7 | ❌ | 端口最多（8 路传感器 + 8 路电机），但依然只能下载程序 |
| M5 | ❌ | 入门款，3 路传感器 + 2 路电机 |
| M6 | ❌ | 5 路传感器 + 4 路电机 |
| E3 | ❌ | 技术风暴主控 |
| C7 | ❌ | 可以在屏幕上直接编程，但仍是"下载—运行" |
| **H-RCU** | ✅ | 跑 Android，可以装应用 |
| **灵芯派** | ✅ | 官方演示里已经把 OpenClaw 跑在上面了 |

> [!IMPORTANT]
> **端口多 ≠ 能被 AI 直接操控。**
> 端口多，是能搭更复杂的机构；能不能被 AI 直接操控，只取决于它开不开放实时指令接口。

## 三个问题，自测一下

- [ ] **1. 你要的是"能改主意"，还是"重复做一件事"？**
  重复做的事（走固定路线、到点抓取）→ 写程序就行，别上 Agent。

- [ ] **2. 你能接受半秒以上的延迟吗？**
  不能接受 → 闭环必须放在机器人身上，Agent 只在远处下命令。

- [ ] **3. 你会接线、会调驱动、会算电流吗？**
  不会 → 先做"外挂"那一档，别一上来换板子。

> 三个都偏向"是、能、会"？那你可能真的需要换脑。
> 有一个卡住，就先停在更便宜的那一档。

## 三个常见误区

| ❌ 误区 | ✅ 实际情况 |
|---|---|
| **"它有 WiFi，所以 AI 能控制它"** | 那个 WiFi 是给下载程序和手机遥控用的，**不是给外部程序发动作的通道** |
| **"装了 Agent 就更智能"** | Agent 只在"规则说不清、需要临场判断"时有用；规则说得清的事，写死更稳 |
| **"传感器越多越强"** | 传感器决定它**能看到什么**，动作还得控制器执行。眼睛再好，手不听话也没用 |
