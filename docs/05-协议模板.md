# 05 协议模板：指令、遥测、ACK、看门狗

## 一条 topic 走双向：前缀法

多数教育机器人平台只给你一条可用的 topic，双向都用它。用前缀区分消息类型，避免解析歧义：

| 前缀 | 方向 | 含义 | 示例 |
|---|---|---|---|
| `T:` | 机器人 → Agent | 遥测 | `T:VIS,red,120,86` |
| `C:` | Agent → 机器人 | 指令 | `C:F2` |
| `A:` | 机器人 → Agent | 指令确认 | `A:F2` |
| `H:` | 机器人 → Agent | 心跳 | `H:12876` |
| `E:` | 机器人 → Agent | 事件 | `E:LOST` |

格式约定：`前缀 + 类型 + 逗号分隔字段`，字段内不出现逗号与换行；保留一个 `V:` 版本前缀字段方便升级（例：`T:VIS,1,red,120,86`）。

## 指令设计五原则

1. **宏动作优先**：一条指令完成一个可观察的行为（前进 1 秒、转 90°），而不是给一个持续速度。
2. **幂等**：同一条指令重复执行结果一致；`STOP` 永远安全。
3. **带序号 + ACK**：`C:12,F2`，机器人回 `A:12,F2`；上位机等到 ACK 再发下一条。
4. **看门狗**：机器人端 3 秒收不到任何 `C:` 就停车，且不依赖网络可达。
5. **限速**：上位机侧做最小发送间隔（建议 ≥ 300 ms），并在软件层限制速度上限。

## 参数怎么传

| 控制器能力 | 参数表达 | 例子 |
|---|---|---|
| 只能字符串比对 | 分档枚举 | `F30 / F60 / F90`，`S1A / S1B / S1C` |
| 能解析字符串/数值 | 键值或 CSV | `C:M,60,1000`（速度 60，时长 1000 ms） |
| 可跑自定义协议 | 定长二进制 | 4 字节：cmd, speed, duration_hi, duration_lo |

判断方法：在控制器端写一条"能否把字符串切成数字"的实验。切不了，就只能分档。

## 命令表示例（YAML，供桥接与文档共用）

```yaml
version: 1
watchdog_ms: 3000
min_interval_ms: 300
commands:
  F1: {action: forward, speed: 30, duration_ms: 1000}
  F2: {action: forward, speed: 60, duration_ms: 1000}
  F3: {action: forward, speed: 90, duration_ms: 800}
  B1: {action: backward, speed: 40, duration_ms: 800}
  L1: {action: turn_left, speed: 50, duration_ms: 500}
  L2: {action: turn_left, speed: 50, duration_ms: 900}
  S1A: {action: servo, id: 1, angle: 30}
  S1B: {action: servo, id: 1, angle: 90}
  STOP: {action: stop, servo_center: true}
```

## 遥测格式建议

| 类型 | 字段 | 示例 | 建议频率 |
|---|---|---|---|
| VIS | 类别, x 偏移, 框宽 | `T:VIS,red,120,86` | 10 Hz |
| US | 距离 cm | `T:US,35` | 2 Hz |
| IMU | 偏航角 | `T:IMU,12.4` | 5 Hz |
| HB | 运行毫秒 | `T:HB,12876` | 1 Hz |

规则：**变化才发**（视觉坐标死区内不重复上报），并给每条消息加最小间隔，避免刷满平台缓存。

## 看门狗伪代码

```
last_cmd_ms = 0
每 50 ms:
  若 收到 C: → last_cmd_ms = now；执行；回 A:
  若 now - last_cmd_ms > 3000 → 电机停、舵机保持、上报 E:TIMEOUT
```

注意：看门狗的超时必须大于"最慢一条指令的执行时长"，否则长动作会被自己的看门狗打断。

## 常见坑

| 坑 | 表现 | 修法 |
|---|---|---|
| 轮询覆盖 | 连发两条，只执行了后一条 | ACK + 序号，等确认再发 |
| 前缀不透传 | 机器人收到的字符串多了 `>>` 之类 | 先用最小实验确认，再定比对字符串 |
| 消息截断 | 长字符串被模块截短 | 控制单条 ≤ 32 字节，长文本拆包 |
| 时区/时钟漂移 | 心跳时间不可比 | 只用相对时间（毫秒计数） |
| 事件风暴 | 同一事件连发数十条 | 事件去抖：2 秒内同类型只发一次 |
