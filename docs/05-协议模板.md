# 05 协议：指令怎么发、回什么、掉线怎么办

## 一条通道两头用：加前缀

多数教育机器人平台只给你一条可用的通道，双向都走它。用开头几个字符区分类型，免得解析乱：

| 前缀 | 方向 | 含义 | 例子 |
|---|---|---|---|
| `T:` | 机器人 → AI | 上报数据 | `T:VIS,red,120,86` |
| `C:` | AI → 机器人 | 下指令 | `C:F2` |
| `A:` | 机器人 → AI | 确认收到 | `A:F2` |
| `H:` | 机器人 → AI | 心跳 | `H:12876` |
| `E:` | 机器人 → AI | 事件 | `E:LOST` |

格式：`前缀 + 类型 + 逗号分隔的值`，值里不要再出现逗号或换行。留一个版本号字段，方便以后升级（例：`T:VIS,1,red,120,86`）。

## 指令怎么设计（五条）

1. **整套动作优先**：一条指令做完一个看得见的行为（前进 1 秒、转 90°），别给一个持续速度。
2. **重复发结果一样**：同一条指令发两遍，动作一样；`STOP` 永远安全。
3. **带序号 + 回确认**：`C:12,F2`，机器人回 `A:12,F2`；发完等确认，再发下一条。
4. **自动停车**：机器人 3 秒收不到任何 `C:` 就停，而且不依赖网络是否还通。
5. **限速**：上位机两条指令之间至少隔 300 毫秒，软件里再限一个最高速度。

## 参数怎么传

| 主控的本事 | 参数怎么给 | 例子 |
|---|---|---|
| 只会比对字符串 | 分档 | `F30 / F60 / F90`，`S1A / S1B / S1C` |
| 能把字符串切出数字 | 键值或逗号分隔 | `C:M,60,1000`（速度 60，时长 1000 毫秒） |
| 能跑自定义协议 | 定长二进制 | 4 字节：指令、速度、时长高位、时长低位 |

怎么判断？在主控端写一条"能不能把字符串切成数字"的实验。切不了，就只能分档。

## 指令表示例（YAML，桥接和文档共用一份）

```yaml
version: 1
watchdog_ms: 3000
min_interval_ms: 300
commands:
  F1: {action: forward, speed: 30, duration_ms: 1000}
  F2: {action: forward, speed: 60, duration_ms: 1000}
  F3: {action: forward, speed: 90, duration_ms: 800}
  B1: {action: backward, speed: 40, duration_ms: 800}
  L1: {action: turn_left, speed: 50, duration_ms: 500}
  L2: {action: turn_left, speed: 50, duration_ms: 900}
  S1A: {action: servo, id: 1, angle: 30}
  S1B: {action: servo, id: 1, angle: 90}
  STOP: {action: stop, servo_center: true}
```

## 上报什么

| 类型 | 字段 | 例子 | 多久一次 |
|---|---|---|---|
| VIS | 类别, 画面偏移, 框宽 | `T:VIS,red,120,86` | 每秒 10 次 |
| US | 距离（厘米） | `T:US,35` | 每秒 2 次 |
| IMU | 偏转角 | `T:IMU,12.4` | 每秒 5 次 |
| HB | 运行了多少毫秒 | `T:HB,12876` | 每秒 1 次 |

规则：**变了才发**（画面位置在死区内不重复报），并给每类消息设最小间隔，别把平台缓存刷满。

## 自动停车的写法

```
last_cmd_ms = 0
每 50 毫秒:
  如果 收到 C: → last_cmd_ms = 现在；执行；回 A:
  如果 现在 - last_cmd_ms > 3000 → 电机停、舵机保持、上报 E:TIMEOUT
```

注意：超时时间必须比你最长的一条动作还长，否则长动作会被自己的自动停车打断。

## 常见坑

| 坑 | 表现 | 怎么改 |
|---|---|---|
| 连发覆盖 | 发了两条，只执行了后一条 | 加序号 + 确认，等确认再发 |
| 前缀被吞 | 机器人收到的字符串多了 `>>` 之类 | 先做最小实验，再定要比对的字符串 |
| 消息被截断 | 长字符串被模块截短 | 单条控制在 32 字节以内，长的拆包 |
| 时间对不上 | 心跳时间没法比 | 只用相对时间（毫秒计数） |
| 事件刷屏 | 同一件事连发几十条 | 去抖：2 秒内同类型只发一次 |
