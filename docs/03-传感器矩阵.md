# 03 传感器矩阵：输出带宽决定智能上限

## 矩阵

| 传感器 | 输出形态 | 典型更新率 | 信息带宽 | 可支撑的闭环 | 典型坑 |
|---|---|---|---|---|---|
| AI 视觉模块（K210 类） | 类别 + 框坐标/偏移 + 框宽高 | 10–30 Hz | 中 | 目标跟随、识别、分拣、找物 | 光照与模型决定稳定性；框宽高只是距离代理，不是真实距离 |
| 直连摄像头（板载算力） | 原始帧 | 15–60 Hz | 高 | 视觉伺服、抓取、精细对准 | 带宽与算力；帧一多，延迟就上来 |
| 超声波 | 距离 cm（单值） | 5–10 Hz | 低 | 安全闸、定距、粗略避障 | 波束窄（约 15°）、软质吸音、多机互扰、测不到斜面 |
| 红外/触碰 | 0 / 1 | 高 | 极低 | 碰撞检测、贴边 | 只报"碰到了"，不报"还有多远" |
| 循迹阵列 | 7 路二值 | 高 | 低 | 巡线、边线保持 | 阈值随场地反光漂移，要现场标定 |
| 颜色传感器 | RGB 或分类 | 中 | 低 | 分色、色标停靠 | 白平衡与光照色温影响巨大 |
| 编码器 | 计数 / 速度 | 高 | 中 | 里程闭环、直行纠偏、定距 | 轮径与打滑误差会累积 |
| IMU | 姿态角 / 角速度 | 高 | 中 | 转向闭环、保持朝向 | 零漂，需要静态校准 |
| 麦克风 / 语音 | 音量或识别结果 | 低 | 低 | 唤醒、口令触发 | 噪声环境下误触发 |

## 带宽决定智能层级

| 感知信息 | Agent 能做的判断 |
|---|---|
| 一个数字（距离 / 音量 / 0-1） | 阈值判断：近了就停、响了就转 |
| 一个分类 + 一个坐标 | 定向动作：往左一点、追这个色块 |
| 一帧图像 | 场景理解：这是什么、能不能过去、该抓哪个 |

所以 **"有 AI 视觉模块" 不等于 "能做视觉智能"**。模块把画面压成了一个类别和一组坐标，Agent 拿到的信息量本来就有限。真要做视觉伺服，得把帧交给能算帧的地方。

## 两个反直觉结论

1. **对控制来说，刷新率比精度重要。** 一个 ±5 cm 但 20 Hz 的测距，比 ±1 cm 但 2 Hz 的测距更好用；后者会让控制环变成"瞎子摸象"。
2. **低带宽传感器的价值是"判定"，不是"感知"。** 超声不该用来跟人，它该用来回答"离墙是不是小于 20 cm"这一个问题。把它放在安全闸上，比放在主控上可靠得多。

## 组合模板

| 任务 | 感知组合 | 控制归属 |
|---|---|---|
| 定距跟随 | 视觉框宽高（主）+ 超声（安全闸） | 控制器 |
| 巡线 | 循迹阵列 + 编码器 | 控制器 |
| 找物抓取 | 直连摄像头 + 舵机云台 | 板载 Agent |
| 避障前行 | 超声 + 触碰 | 控制器（Agent 只发"去哪"） |
| 语音指令任务 | 麦克风唤醒 + Agent | Agent（板载或云端） |

## 标定期清单

传感器不是接上就能用，以下每一项都会改变阈值：

- [ ] 现场光照（自然光 / 日光灯 / 台灯）下重测颜色与视觉阈值
- [ ] 场地反光下重测循迹阈值
- [ ] 超声对目标材质（衣物、海绵、玻璃）实测有效距离
- [ ] IMU 静止 30 秒，记录零漂
- [ ] 编码器走 1 米，实测计数，算出每米脉冲
